V4.4.2 SOUND FIX
- New default Config.SoundMode = 'synth': pops, bangs and mega bangs are generated by the
  resource itself (html/index.html, Web Audio). No GTA audio banks / soundsets needed,
  so they cannot silently fail to load. Volume and muffling scale with distance
  (Config.SoundVolume, Config.SoundRange). Nearby players hear them via the synced event.
- Config.SoundMode = 'native' switches back to the GTA soundsets (optional `bank` per sound).
- /antilagtest plays pop, pop, bang, pop, mega (with flames if you are in a vehicle).
- Startup prints so you can confirm the right copy is running:
    server console: [sp_antilag] v4.4.2 loaded from <folder path>
    F8 console:     [sp_antilag] client v4.4.2 loaded (sound mode: synth)

TROUBLESHOOTING
If the server console shows warnings about html/app.js or html/sounds/*.wav, or F8 shows
'StartParticleFxNonLoopedOnEntityBone', an OLD copy of sp_antilag is being loaded instead
of this one. Delete every other sp_antilag folder in your resources.
