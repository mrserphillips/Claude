sp_parkmusic - gentle music around Legion Square park
======================================================

1. Put the sp_parkmusic folder in your resources (fxmanifest.lua directly inside it).
2. Add to server.cfg:   ensure sp_parkmusic
3. Restart. No database, no dependencies.

How it works
- When a player spawns / loads their character, the music slowly fades in (8s by default)
  if they are at Legion Square park.
- Volume follows distance: full (but soft) volume inside the park, drifting to silent
  as they walk away. Audio is fully paused when out of range, so it costs nothing.
- Each player can toggle it with /parkmusic (remembered between sessions).

Music
- Drop your music files (.ogg, .mp3, .wav or .webm) into:  sp_parkmusic/html/music/
- Restart the resource (restart sp_parkmusic) so the new files get sent to players.
- The files play one after another (alphabetical order), then loop back to the first.
  Number the file names (01_song.mp3, 02_song.mp3...) to control the order,
  or set Config.Shuffle = true for a random order.
- The server console prints which tracks it found when the resource starts.
- If the folder is empty, generated calm ambient music (soft pads + chimes) plays instead.
- .ogg or .mp3 is recommended. Only use music you have the rights to play.

Tweak position, radius, volume and fade times in config.lua.

Troubleshooting: "it plays ambient music, not my songs"
- Look at the server console after "restart sp_parkmusic". It prints the music folder path
  and the tracks it found, or why it skipped a file.
- Files must be directly inside html/music/ (not in a sub-folder).
- .m4a / .aac / .wma files can't play in-game - convert them to .mp3 or .ogg.
- "Could not read the music folder": your host blocks folder listing. List the file names
  in Config.Tracks in config.lua instead, then restart the resource.
